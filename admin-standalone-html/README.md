# Admin Studio - Saf HTML / CSS / JavaScript (Sıfır Node.js)

Bu sürüm, **Node.js, npm, Vite veya herhangi bir derleyiciye ihtiyaç duymadan** doğrudan tarayıcıda çalışan tam işlevsel Yönetici Stüdyosu'dur.

---

## ⚡ Özellikler

1. **Sıfır Kurulum:** Herhangi bir `npm install` veya `npm run dev` yapmanıza gerek yoktur. `index.html` dosyasına çift tıklayarak doğrudan tarayıcınızda açabilirsiniz.
2. **Çok Kurumlu Giriş (Multi-Tenant Auth):** E-posta ve şifrenizle giriş yapabilir veya yeni kurum kaydı oluşturabilirsiniz.
3. **Canlı 1:1 WYSIWYG Önizleme:** Seçilen şablonun birebir canlı görünümü ekranda render edilir.
4. **Tıkla-Düzenle Popupları:** Başlık, Medya Slayt (Dosya yükleme dahil), Bilgi Tablosu ve Kayan Yazı alanlarına tıklayarak doğrudan düzenleyebilirsiniz.
5. **Pano Filo Yönetimi:** PIN ile yeni panoları eşleştirebilir, online/offline durumlarını ve CPU telemetrilerini izleyebilirsiniz.
6. **Acil Tahliye Sireni:** Tek tıkla tüm panolara kırmızı siren tahliye ekranı gönderebilirsiniz.
7. **Taşınabilir:** Herhangi bir statik sunucuda (Nginx, Apache, GitHub Pages, yerel disk) doğrudan çalışır.

---

## 🚀 Nasıl Kullanılır?

1. `admin-standalone-html/index.html` dosyasına çift tıklayarak tarayıcınızda açın.
2. Sunucu adresiniz varsayılan olarak `https://pano.teknovip.net` olarak gelecektir.
3. Giriş yaparak panolarınızı yönetmeye başlayın!
